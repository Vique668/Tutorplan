# TutorPlan

Frontend-прототип кабинета репетитора на Next.js, TypeScript и App Router.

## Запуск

```bash
npm install
npm run dev
```

Приложение откроется на [http://localhost:3000](http://localhost:3000). Главная страница автоматически перенаправляет на `/calendar`.

## Разделы

- календарь и недельное расписание;
- ученики и учебные группы;
- финансы и статистика;
- настройки профиля.
- автоматические сезонные темы с ручным выбором в настройках.

Все данные демонстрационные. База данных, Supabase и аутентификация не подключены.
